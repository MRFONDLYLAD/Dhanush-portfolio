Selected projects

GAIN and MICE for missing data

August 2024. Oral presentation, ISMS Conference 2024, Varanasi

Compared two ways of imputing missing data, GAIN (a generative adversarial network method) and MICE, under various scenarios.

About the methods

MICE imputes each incomplete variable with a model based on the other variables, and repeats this to create several completed datasets. GAIN trains a neural network to fill in missing values. The project compared how well each performed.

Support vector machine and random forest on ICU data

March 2023. Poster, ConSPIC, Bangalore

Compared the performance of the two machine-learning algorithms on an intensive care unit dataset.

About the methods

A support vector machine separates groups with the widest possible margin. A random forest combines the predictions of many decision trees. Both learn from labelled examples.
